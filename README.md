# utility-bills-compare

Ежемесячное сравнение платы за жилищные и коммунальные услуги для одной и той же квартиры в шести городах: Ереван, Тбилиси, Белград, Варшава, Лиссабон, Берлин. Тарифы, дома, курсы и погода собираются сами; человек видит сбой или резкий скачок, а не вносит цифры руками.

Сайт — статические HTML, CSS и vanilla JS на GitHub Pages (без сборки фронтенда): с телефона страница открывается быстро и ей не нужен шагом сборки. Сбор, разбор страниц и расчёт — Python 3.12: на нём писались прототипы источников, и для HTML/PDF есть готовые библиотеки. Почему стек такой и как устроены контракты — в [AGENTS.md](AGENTS.md). Словарь — в [GLOSSARY.md](GLOSSARY.md).

- Карта решений: [issue #1](https://github.com/Anwert/utility-bills-compare/issues/1)
- Спецификация: [issue #18](https://github.com/Anwert/utility-bills-compare/issues/18)

Скрипты-прототипы (PoC) источников не лежат в этом репозитории. Адаптеры пишутся по тикетам и проверяются на сохранённых страницах.

## Установка

Нужен Python 3.12.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

## Тесты и линтер

Сеть в тестах запрещена: адаптеры читают файлы из `tests/fixtures/`.

```bash
ruff check .
```

## Конвейер локально

Команда проверяет схемы и показывает, сколько источников включено в конфигурации городов. Списки источников пока пустые: их заполняют тикеты адаптеров. Сбор страниц, расчёт ячеек и публикация на GitHub Pages в эту команду не входят.

```bash
python -m ubc.pipeline --check
python -m ubc.pipeline
python -m ubc.pipeline --city yerevan --period 2026-10
```

`--period YYYY-MM` задаёт месяц сбора. Команда передаёт его в контекст каждого включённого источника и сайта объявлений и по-прежнему ничего не скачивает.

`--check` завершается с кодом 0, когда валидны шесть городов, эталонная квартира (2 комнаты, 60 м², 2 жильца) и пример JSON для сайта `data/examples/yerevan-2026-10.json`. Неверный файл завершает команду с кодом 1.

## Где лежат договорённости

- `data/cities/` — валюта, координаты и статьи каждого города
- `data/reference.json` — эталонная квартира и заглушки норм расхода
- `data/examples/yerevan-2026-10.json` — пример данных, которые читает сайт (цифры примерные)
- `ubc/schemas.py` — проверка этих документов
- `ubc/adapters/example_html.py` — образец адаптера на фикстуре
