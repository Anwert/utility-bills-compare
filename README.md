# utility-bills-compare

Ежемесячное сравнение платы за жилищные и коммунальные услуги для одной и той же квартиры в шести городах: Ереван, Тбилиси, Белград, Варшава, Лиссабон, Берлин. Тарифы, дома, курсы и погода собираются сами; человек видит сбой или резкий скачок, а не вносит цифры руками.

Сайт — статические HTML, CSS и vanilla JS на GitHub Pages (без сборки фронтенда): с телефона страница открывается быстро и ей не нужен шагом сборки. Сбор, разбор страниц и расчёт — Python 3.12: на нём писались прототипы источников, и для HTML/PDF есть готовые библиотеки. Почему стек такой и как устроены контракты — в [AGENTS.md](AGENTS.md). Словарь — в [GLOSSARY.md](GLOSSARY.md).

- Карта решений: [issue #1](https://github.com/Anwert/utility-bills-compare/issues/1)
- Спецификация: [issue #18](https://github.com/Anwert/utility-bills-compare/issues/18)

Скрипты-прототипы (PoC) источников не лежат в этом репозитории. Адаптеры пишутся по тикетам и проверяются на сохранённых страницах.

## Установка

Нужен Python 3.12.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

## Конвейер локально

Без `--run` команда проверяет схемы и показывает, сколько источников включено в конфигурации городов. Градусо-сутки уже берутся из Open-Meteo, курсы PLN, AMD, GEL и RSD — из официальных источников; списки статей заполняют тикеты адаптеров.

```bash
python -m ubc.pipeline --check
python -m ubc.pipeline
python -m ubc.pipeline --city yerevan --period 2026-10
```

`--period YYYY-MM` задаёт месяц сбора. Команда передаёт его в контекст каждого включённого источника и сайта объявлений и по-прежнему ничего не скачивает.

`--check` завершается с кодом 0, когда валидны шесть городов, эталонная квартира (2 комнаты, 60 м², 2 жильца) и пример JSON для сайта `data/examples/yerevan-2026-10.json`. Неверный файл завершает команду с кодом 1.

### Месячный прогон

```bash
python -m ubc.pipeline --run
python -m ubc.pipeline --run --city yerevan --period 2026-10 --dry-run
python -m ubc.pipeline --run --city yerevan --item gas
```

`--run` собирает источники, выбирает значения, закрепляет дома, считает ячейки и пишет `data/`. Без `--period` берётся прошедший месяц. `--dry-run` ничего не пишет и не отправляет. Нужны `pdftotext` (poppler) и Chrome. Если чего-то не хватает для честного счёта, команда завершается с кодом 1 и не меняет ни одного файла.

Что остаётся в репозитории: `data/<город>-<YYYY-MM>.json` для сайта, `data/normalized/` — записи всех источников, `data/state/` — действующие значения и их история, `data/houses/` — закреплённые дома, `data/raw/` — сырые ответы (`tar -xJf`).

В GitHub Actions то же делает `.github/workflows/monthly.yml`: 7-го числа за прошедший месяц и вручную с выбором города, статьи и месяца. Он коммитит данные и выкладывает сайт. Упавший прогон ничего не коммитит и не публикует, но уведомления `data-alert` о сломанных источниках отправляет.

## Прокси и ИИ

Оба выключены, пока в окружении нет секретов, и в этом режиме никуда не подключаются. Политика их пропускает и берёт следующий источник (статистика или сторонний сайт) с пометкой о доплате из файла города.

- Прокси: `PROXY_HOST`, `PROXY_LOGIN`, `PROXY_PASSWORD`, `PROXY_COUNTRY`. Источник с `"kind": "proxy_direct"` и тем же `adapter`, что у страницы. Страна на источнике — `settings.country`. Транспорт передаётся в `fetcher_for_source`; встроенная заготовка соединение не открывает.
- ИИ-разбор: адаптер `llm_extract` и секрет `LLM_API_KEY`. Без ключа источник выключен. Ответ модели проверяется правилами (единица, диапазон, дата не дальше 3 месяцев, бытовые потребители, цитата в тексте, возрастающие ступени). Свой клиент модели подключается к адаптеру; заготовка сама в API модели не ходит.
- Пометка «точные данные возможны за доплату» — поле `paid_data_note` в `data/cities/<город>.json`. Для статей уровня `statistics` и `third_party` её отдаёт `paid_data_note(city, reliability)`.

Как включить оба способа по шагам — в [AGENTS.md](AGENTS.md).

## Сайт

Статическая страница без сборки: вкладки городов, месяц, сетка 3×3, разбивка по нажатию. Пока конвейер не записал свои файлы, она показывает пример `data/examples/`. Пустая ячейка серая, с причиной. Город без файла месяца остаётся вкладкой с пояснением, без выдуманных цифр.

Список файлов лежит в `data/site-index.json`. Туда входят `data/examples/<город>-<YYYY-MM>.json` и, когда они появятся, `data/<город>-<YYYY-MM>.json`. После нового файла индекса:

```bash
python -m ubc.site_index
```

Открыть локально (просто открытый файл не загрузит JSON):

```bash
python -m http.server
```

Страница: <http://127.0.0.1:8000/>. На ширине телефона те же вкладки и сетка.

На Pages выкладывается только страница и опубликованные месяцы:

```bash
python -m ubc.site_bundle _site
```

## Где лежат договорённости

- `data/cities/` — валюта, координаты и статьи каждого города
- `data/reference.json` — эталонная квартира и нормы расхода с источниками
- `data/examples/yerevan-2026-10.json` — пример данных, которые читает сайт (цифры примерные)
- `ubc/schemas.py` — проверка этих документов
- `ubc/adapters/example_html.py` — образец адаптера на фикстуре
